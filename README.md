# 💜 CLYPORYN

### Your clipboard. Reimagined.

**A modern, powerful, and lightweight clipboard manager for Windows.**

Stop losing copied content. CLYPORYN automatically saves your clipboard history and makes everything accessible in seconds.

| Feature | Description |

## 📥 Download & Installation

**CLYPORYN is currently available for Windows 10 and 11 (64-bit).**

1. Visit the [latest release](https://github.com/notnotw23132/CLYPORYN/releases/latest).
2. Download `CLYPORYN-Setup-Custom-1.0.0.exe` (or the latest available version).
3. Launch the installer.
4. Select your language and installation preferences.
5. Start using CLYPORYN!

No Node.js or development tools are required to install the application.

> **Windows security notice:** Windows SmartScreen may display a warning because CLYPORYN is a new, unsigned application. Only download installers from the official repository.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + \` | Open the quick clipboard overlay |
| `Ctrl + K` | Open the command center |
| `Ctrl + F` | Search clipboard history |
| `Esc` | Close the current overlay or dialog |
| `↑` / `↓` | Navigate clipboard entries |
| `Enter` | Select a clipboard entry |

## 🔄 Automatic Updates

CLYPORYN checks GitHub Releases for newer versions.

When an update is available, the application can download it, verify its SHA-256 checksum, and start the update process after your confirmation.

Updates are designed to preserve your existing clipboard history and settings.

---

## 🔐 Privacy

Your clipboard history is stored locally on your device.

- No account required.
- Core clipboard functionality works offline.
- No cloud upload required for clipboard history.
- GitHub connectivity is used to check for updates.

**Important:** Clipboard history may contain sensitive information. Review and delete entries you do not want to retain.

## 🛠️ Build from Source

Developers can build CLYPORYN locally using Node.js and npm.

```bash
cd CLYPORYN/windows-app
npm install
npm run dist:win
```

The Windows installer will be generated in the `dist` directory after a successful build.
